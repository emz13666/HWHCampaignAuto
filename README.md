# HWHCampaignAuto

Расширение (userscript) для игры **Hero Wars** / **Хроники Хаоса**, работающее поверх [HeroWarsHelper](https://zingery.ru/scripts/HeroWarsHelper.user.js). Автоматически проходит кампанию по заданному диапазону миссий: с рейдом на 3★, с автоопределением стартовой точки, с показом названий миссий и понятной причиной остановки.

## Возможности

- ⚔️ **Автопрохождение кампании** по диапазону `[first..last]`, с настраиваемым количеством повторов на миссию.
- 🚀 **Рейд на 3★** — если миссия уже пройдена на 3 звезды, вместо боя выполняется `missionRaid` (мгновенно, без энергии на бой).
- 🔍 **Автоопределение стартовой миссии** — если указанная «первая» миссия ещё заблокирована, скрипт сам откатывается до первой непройденной (никаких «Previous mission not completed»).
- 🏷️ **Названия миссий** — в статусе и в диалоге настроек отображается локализованное имя миссии: `134 «Ворота Стронгфорда»`.
- 🎯 **Понятные причины остановки**: последняя миссия достигнута, поражение, не хватает энергии, нет попыток, миссия заблокирована, ошибка сервера, остановлено пользователем.
- 🖱️ **Стоп — клик по статусу.** Пока кампания идёт, сверху горит статус, по клику выполняется корректная остановка (текущий бой при этом доигрывается, чтобы не оставить серверную сессию «висящей»).
- 💾 **Запоминание настроек** — все поля сохраняются в `localStorage` автоматически (даже при «Отмена»).
- ↩️ **Шорткат «продолжить с прошлого запуска»** — кнопка в диалоге, которая одним кликом ставит в «Первую миссию» номер, на котором остановился прошлый запуск. Кнопка гаснет, если значение уже стоит, и снова зажигается при любом другом значении.
- ⚡ **Учёт энергии** — скрипт знает стоимость миссии (из `lib.data.mission[id].normalMode.teamExp`), отслеживает текущую энергию и останавливается **до** попытки стартовать миссию, если её не хватает.
- 🧩 **Интеграция с HWH** — отдельная кнопка **«Кампания»** в меню «Действия», а также галочка **«Кампания (авто)»** в меню **«Сделать всё»** HeroWarsHelper.
- 🛡️ **Мягкая деградация** — если HWH не найден, показывается всплывающее окно с просьбой установить HeroWarsHelper, а скрипт продолжает периодически проверять его появление.

## Установка

1. Установите менеджер userscript-ов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Opera, Firefox)
   - [Violentmonkey](https://violentmonkey.github.io/) (Firefox)
   - [Greasemonkey](https://www.greasespot.net/) (Firefox)

2. Установите **HeroWarsHelper** (обязательно, скрипт работает только поверх него):
   - [HeroWarsHelper.user.js](https://zingery.ru/scripts/HeroWarsHelper.user.js)

3. Установите **HWHCampaignAuto**:
   - **[⬇ Установить HWHCampaignAuto](https://github.com/emz13666/HWHCampaignAuto/raw/refs/heads/main/HWHCampaignAuto.user.js)**

4. Откройте игру — [hero-wars.com](https://www.hero-wars.com/), [hero-wars.cn](https://www.hero-wars.cn/) или Facebook-версию.
